# Git and GitHub 1.3 - Forks and Pull Requests

## What I Learned

I learned that a fork creates a copy of another repository in my own GitHub account. I also learned that a pull request is used to propose changes to a repository and allows the changes to be reviewed before they are merged.

## Fork

A fork is useful when I want to work on a project without directly changing the original repository.

## Pull Request

A pull request allows me to submit my changes and ask the repository owner to review and merge them.
